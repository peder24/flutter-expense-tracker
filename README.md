# Expense Tracker App

A Flutter-based mobile application for tracking daily expenses with real-time analytics visualization and category-based financial monitoring.

This application allows users to add, manage, and analyze expenses through an interactive and responsive dark-themed user interface.

## Features
- Add and delete expense records
- Category-based expense management
- Real-time total expense calculation
- Interactive Pie Chart analytics using fl_chart
- Dynamic expense aggregation by category
- Recent expense activity tracking

## Technologies Used
- Flutter
- Dart
- fl_chart

## Application Workflow
User Input
   ↓
Expense Management
   ↓
Data Aggregation
   ↓
Analytics Visualization
   ↓
Expense Monitoring

## Run Project
1. Clone Repository
git clone <repository-url>
2. Navigate to Project
cd expense_tracker
3. Install Dependencies
flutter pub get
4. Run Application
flutter run
